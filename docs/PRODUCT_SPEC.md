# Project Axiom — product specification

Working title only. The final brand will be selected after a trademark search.

## Product promise

A private, expressive Windows companion that can converse naturally, perceive presence locally, remember with user control, and perform transparent computer actions through explicit permissions.

## Differentiators

1. A procedural “living signal” avatar rather than a copied cinematic character.
2. Local-first presence and expression processing; camera frames are not uploaded for animation.
3. Provider-independent cognition with health-aware fallback.
4. A visible action ledger: the user can see what was attempted, permitted, verified, or blocked.
5. Memory with provenance, confidence, expiration, and per-item deletion.
6. Emotion as a disclosed interaction model—not a claim of consciousness.
7. Reversible automation and least-privilege tool permissions.

## Initial milestone

- Windows desktop shell and installer.
- Original reactive avatar with idle, listening, thinking, speaking, success, warning, and error states.
- OpenAI Responses integration isolated in the Electron main process.
- OS-encrypted API-key storage.
- Typed IPC bridge with context isolation.
- Local conversation history.
- Low-risk read-only tools and a permission framework for future actions.
- Automated state and provider-parser tests.

## Later milestones

- On-device face, gaze, pose, and gesture tracking.
- Audio-driven visemes and optional premium TTS.
- Sandboxed PowerShell and desktop-control adapters.
- Durable semantic memory with citations.
- Skills, schedules, connectors, updater, crash reporting, and signed releases.
