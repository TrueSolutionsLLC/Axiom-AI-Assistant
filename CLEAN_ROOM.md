# Clean-room declaration

Project Axiom is an independently authored application. It must not incorporate source code, object code, assets, UI copy, icons, sounds, models, activation systems, identifiers, or branding from any previously purchased assistant.

## Allowed inputs

- High-level capabilities requested by the product owner.
- Public protocols and official API documentation.
- Dependencies with verified redistribution licenses.
- Newly authored code, artwork, audio, models, copy, and designs.
- General functional ideas such as voice interaction, local memory, reactive animation, tool execution, and person tracking.

## Prohibited inputs

- Copying or translating code from the purchased application.
- Pixel-matching its screen or reproducing its distinctive layout.
- Reusing its skull mesh, sounds, icons, wording, prompts, product name, licensing service, or file formats.
- Using extracted implementation details as shortcuts.

## Process

Every nontrivial asset and dependency is recorded in `docs/ASSET_PROVENANCE.md`. A final commercial release requires an independent license audit and trademark review.
